# UI Primitive Library

This directory contains the foundational, reusable building blocks of the TradeEasy design system. 
Built on top of Radix UI primitives and styled via Tailwind CSS `cva` (Class Variance Authority), these components ensure 100% visual consistency across the app.

* **Design Philosophy:** Clean, flat, high-contrast interfaces with subtle glassmorphism (`backdrop-blur`) and specific attention to financial data density (e.g., monospace numbers, distinct color-coding for profits/losses).
* **Key Components:** Custom Toast notifications, multi-layered Dropdown Menus, accessible Dialogs/Modals, and skeleton loaders for perceived performance.
